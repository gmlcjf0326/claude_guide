# docs/research — 조사 영구 보관소 (research findings archive)
> 🇰🇷 `/research`가 조사 결과를, `/setup`·`/spec`이 inputs/에서 증류한 재사용 가능한 기술 발견을 여기에 영구 저장합니다. 한 번 조사한 것은 두 번 검색하지 않습니다.

- One file per topic: `docs/research/<topic>.md` — findings, sources, date, and a one-line verdict.
- Written by `/research <topic>`, and by `/setup`/`/spec` when distilling reusable technical findings from `docs/inputs/`.
- Never auto-loaded (zero idle token cost) — cite on demand when the topic comes up.
